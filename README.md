# RAML vs GADGET

全4章のRPG風アドベンチャー。ブラウザで遊べます。

**▶ [プレイする](https://turu00260026.github.io/raml-vs-gadget/)**

## これはどんな話か

街の手続きが、ある夜いっせいに消えた。

「世界中の承認待ちを、全面廃止する」——そう言ってツールを放ったのは GADGET のケイスケ。
止めに行くのは RAML の四人。リコ、ノリ、レントン、ショウ。

戦うことより、**どう止めるかを選ぶ**話です。

## 遊び方

- 選択肢を選んで話を進めます。選んだものは記録に残り、章の結末に効いてきます
- 戦闘では「壊して止める」「掌握して止める」「話して止める」から選べます。**どれを選ぶかで結末が変わります**
- 6つのパラメータ（自由理解・秩序理解・信頼EXP・AI活用・GADGET解析・RAML士気）が積み上がっていきます
- 記録室で、称号・図鑑・戦闘ログ・回想を確認できます

### 戦闘は、力比べではありません

**相手は決まった順番で動いています。** 解析すると、その周期が1拍ずつ見えてきます。

周期の中には **同期のラグ**——全機が指令を取り直す一瞬があり、そこだけ無防備になります。

- **同期している間は硬い。** 力任せに殴っても通りません。連打では削り切れません
- **隙を突いた一撃は3倍**で通ります
- **ただし隙は、読めていた者にしか見えません**

次の一手が読めていれば、それを**先に潰す手**も打てます。一斉射撃は封鎖で射線を切り、防壁再構成は掌握で手順を奪い、割り込み書き換えは保護で生活側を守る。刺されば相手の一手は丸ごと不発になります。

読まずに殴るか、読んで待つか。**それが戦い方の選択です。**

セーブはブラウザに自動保存されます（同じ端末・同じブラウザで続きから遊べます）。
